# انتشارات بنیاد سینمایی فارابی (نمونه)
- اجرا: فایل index.html را در VS Code (Live Server) یا مرورگر باز کنید.
- افزودن کتاب: یک آبجکت جدید به آرایه BOOKS در js/books.js اضافه کنید (cover خالی = جلد گرافیکی خودکار).
- لوگو: assets/images/logo.svg (نماد موقت است؛ لوگوی رسمی را جایگزین کنید). تصویر Hero: بخش hero-art در index.html.
- فونت‌ها: عنوان‌ها Lalezar و متن Noto Sans Arabic از Google Fonts (نیاز به اینترنت). برای حالت آفلاین فایل‌ها را در assets/fonts بگذارید و با @font-face تعریف کنید.
- اطلاعات کتاب‌ها و متن‌ها نمونه و فرضی‌اند.
